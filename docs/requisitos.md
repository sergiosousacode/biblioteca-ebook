# Requisitos — Biblioteca Digital

## Público-alvo

Leitores interessados em poesia, literatura
e histórias populares.

## Interface

A aplicação deve possuir:

- Layout moderno e minimalista.
- Design responsivo.
- Navegação simples.
- Grid de livros com capas ilustradas.
- Pesquisa e filtros por categoria.

## Catálogo

Cada livro deverá apresentar:

- Título.
- Autor.
- Categoria.
- Capa.
- Sinopse.
- Arquivo PDF.

## Leitura

O usuário poderá visualizar o PDF diretamente
no navegador ou baixar o arquivo.

## Administração

Futuramente, somente o administrador poderá
cadastrar, editar e excluir livros.

## Comentários e avaliações

O leitor deverá realizar um cadastro com
e-mail e WhatsApp antes de comentar ou avaliar.

## Primeira etapa

Construir a interface utilizando dados simulados.

Não implementar backend nesta etapa.
